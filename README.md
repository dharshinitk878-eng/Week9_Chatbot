
# Week 9 - AI Chatbot Development

## Project Title
Building an Interactive AI Chatbot Using Ollama

## Description
This project creates an educational AI chatbot
using Python and Ollama.

## Technologies Used
- Python
- Ollama
- Gemma 3
- VS Code

## Features
- Answers educational questions
- Maintains conversation history
- Saves conversations in CSV
- Supports different types of questions

## How to Run
1. Install Ollama.
2. Download Gemma 3.
3. Install the requirements.
4. Run python chatbot.py.

## Model
Gemma 3 1B
